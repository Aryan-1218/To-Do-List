# To-Do List App

A simple To-Do List web application built using HTML, CSS, and JavaScript.  
Users can add tasks and mark them as completed.

## Features
- Add new tasks
- Mark tasks as completed
- Simple and clean UI

## Technologies Used
- HTML
- CSS
- JavaScript
